# Around The U.S.

## 📌 Descripción del proyecto

**Around The U.S.** es una página web interactiva que permite explorar diferentes lugares de Estados Unidos a través de tarjetas con fotografías y títulos descriptivos. El proyecto ofrece una interfaz visual e intuitiva para personalizar un perfil, compartir lugares favoritos e interactuar con las tarjetas.

## ⚙️ Funcionalidades

La página web cuenta con las siguientes funcionalidades:

- **Editar perfil:** permite modificar el nombre y la descripción del perfil mediante una ventana emergente.
- **Agregar tarjetas:** permite crear nuevas tarjetas indicando el título y el enlace de una imagen.
- **Dar "Me gusta":** permite marcar las tarjetas favoritas mediante un botón interactivo.
- **Eliminar tarjetas:** permite eliminar las tarjetas que ya no se desean mostrar.
- **Visualizar imágenes ampliadas:** permite abrir las fotografías en una ventana emergente para verlas en mayor tamaño.
- **Interfaz interactiva:** utiliza JavaScript para gestionar las acciones del usuario y actualizar dinámicamente el contenido de la página.

## 🛠️ Tecnologías utilizadas

Para el desarrollo del proyecto se utilizaron las siguientes tecnologías:

- **HTML5:** estructura y organización del contenido de la página.
- **CSS3:** diseño visual, distribución de los elementos y adaptación de la interfaz.
- **Metodología BEM:** organización y nomenclatura de las clases CSS para facilitar el mantenimiento del código.
- **Flexbox:** distribución y alineación de los elementos de la interfaz.
- **JavaScript:** implementación de la interactividad, gestión de eventos y manipulación dinámica del contenido del DOM.
